# 色差与厚度分析（独立版本）

这是从原 HSV 程序复制并改写的独立版本，不依赖或修改父目录中的程序。双击本目录 `start.bat` 启动；原 HSV 程序仍使用父目录的 `start.bat`。

## 使用流程

1. 点击“打开图片”，导入本地图像。
2. 点击 **background**，再在图片中点击一个背景像素。蓝色标记显示背景点。
3. 点击 **signal**，再点击一个信号像素。黄色标记显示信号点。
4. 两点都选定后，界面显示色差预览；点击“加入拟合”，计算完整精度的色差并添加新行，厚度为空。
5. 在“拟合数据”页双击该行，填写厚度。表格只有“色差 ΔE76”“厚度”两列及参与拟合的勾选开关，不再显示 RGB/HSV 通道数据。
6. 勾选要参与拟合的行，在“拟合”页点击“开始 / 更新拟合”，查看数据点、拟合直线、斜率、截距及 R²。

选点基于原始分辨率像素。可用“适应窗口”看全图，也可用“100% 显示”及滚动条精确定位。每次按 background 或 signal 后只取一个点，需要重选时再次点击对应按钮。当前图片可重复使用同一背景点配合不同信号点；打开任何新图片都会清除两个点，避免跨图混用。取点更改只影响下一条新记录，不会覆盖已添加行。

## 色差定义

采用 **CIE76 ΔE*ab**：先将两个点的 sRGB 编码值解码为线性光值，再转换到 XYZ / CIELAB（D65 白点、2° 标准观察者），计算：

`ΔE76 = sqrt((L_signal - L_background)² + (a_signal - a_background)² + (b_signal - b_background)²)`

色差无量纲，非负，可能大于 100；相同颜色的色差为 0。这里使用 CIE76，不是 RGB 空间欧氏距离，也不是 CIEDE2000。实现依据 [CIE 的 CIELAB 定义](https://cie.co.at/eilv/157)及 [W3C 的 sRGB 转换与色差说明](https://www.w3.org/TR/css-color-4/#color-conversion-code)。本程序使用 D65 作为 Lab 参考白点，不采用 CSS Lab 的 D50 白点。

输入图片统一假定为 sRGB，不读取 ICC 配置进行色彩管理。程序按 EXIF 自动旋转，仅读取多帧/多页图片的第一帧/页；灰度图转换后可正常计算明度色差，透明图片忽略 Alpha 并使用像素存储的颜色，高位深及浮点灰度图会提示先转换为 8 位。请保持各张图片的照明、曝光及白平衡一致。背景配对不等于自动光照或白平衡校正。

## 拟合与数据保护

- 模型：`厚度 = 斜率 × ΔE76 + 截距`，含截距的等权最小二乘拟合。
- 至少勾选两行有效数据，且色差不能全部相同。空白厚度会提示行号，不能静默跳过。
- R² 使用 `1 - Σ(y - ŷ)² / Σ(y - y均值)²`；厚度全部相同时显示“未定义”。
- 新增和导入行默认勾选；可逐行切换或全部勾选/取消。行高亮用于编辑、删除，与拟合勾选独立。
- 修改已有值及删除行均需警告确认，默认“否”。首次填入空白厚度可直接保存。
- 数据或勾选变化会清除旧拟合结果；图片取点变化不改变已保存的表格行。
- 未导出的表格修改在退出前会提醒。

## TXT 导入导出

导出全部行，使用 UTF-8（带 BOM）、Tab 分隔，含表头 `色差 ΔE76` 和 `厚度`；保留完整数值精度与空白厚度。覆盖已有文件时会确认。文件不保存勾选状态、取点坐标、源图片或拟合结果，重新导入后默认全选。

导入会在整份文件校验通过后追加，不覆盖已有行。支持 Tab、英文逗号或空格分隔，空白行忽略；厚度为空时应使用 Tab 或逗号保留空字段。表头可省略，或使用 `色差,厚度`、`DeltaE76,Thickness`。建议保持导出的 Tab 格式；含空格的完整中文表头也必须用 Tab 或逗号分列。

示例（数值仅作格式演示）：

```text
DeltaE76,Thickness
12.5,20
18.2,30
25.1,
```

本版本只接受两列色差数据，不接受旧版 RGB 四列表格，避免混用不同含义的标定量。厚度单位由用户统一，TXT 不记录单位。

## 环境与验证

Python 3.10+、Tkinter、Pillow；无需新增依赖。在本目录运行：

```powershell
python -m pip install -r requirements.txt
python color_difference_inspector.py
python -m unittest discover -s tests -v
python tests/gui_workflow.py
```

单元测试覆盖颜色转换、参考色差、线性拟合和两列 TXT。图形测试使用临时生成的图片验证取点、跨图清空、编辑保护、勾选、拟合、导入导出和窗口布局。
