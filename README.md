# RGB 像素分析工具

本项目包含三个可独立运行的版本，保留不同的厚度标定方法：

| 版本 | 启动入口 | 说明 |
| --- | --- | --- |
| RGB 分析 / HSV 拟合 | `start.bat` | 当前目录，下文介绍此版本 |
| 色差拟合 | `color_difference/start.bat` | [使用说明](color_difference/README.md)，使用 ΔE76 |
| 光学对比度拟合 | `optical_contrast/start.bat` | [使用说明](optical_contrast/README.md)，使用背景归一化的通道对比度 |

版本管理包含程序、依赖清单、使用说明和测试。现有本地测量表、Python 缓存，以及根目录的 `data/`、`results/` 不纳入 Git；后续实验图片和导出数据可保存在这两个目录中。忽略规则不会删除本地文件。

本地桌面程序：导入图片后，单击查看像素的 RGB 值，按住鼠标左键拖拽矩形查看区域内 R、G、B 各通道的均值和标准差。图片不会上传，也不会被修改。

## 启动

Windows 下双击 `start.bat`。启动器依次尝试项目虚拟环境、Python Launcher、当前用户的 Codex 自带 Python，以及 PATH 中的 Python。本机已检测到 Codex 自带 Python 和 Pillow。

在其他环境中，安装 Python 3.10 或更高版本（需要 Tkinter），然后在项目目录运行：

```powershell
python -m pip install -r requirements.txt
python rgb_inspector.py
```

若提示找不到 Tkinter，Windows Python 安装器中启用 Tcl/Tk 组件；Linux 上安装发行版提供的 `python3-tk`。

## 操作

1. 点击“打开图片”或按 `Ctrl+O`，选择本地 PNG、JPEG、BMP、TIFF、WebP 或 GIF。
2. 单击图片：下方面板显示坐标与 RGB 整数值，单像素的均值等于该像素值，标准差为 0。
3. 按住左键拖动至少 3 个屏幕像素，松开后显示矩形的范围、像素数、各通道均值与标准差。支持任意方向拖拽；拖出图像时自动截取到图像边缘。
4. 使用“适应窗口”查看整张图，或使用“100% 显示”和滚动条定位原图像素。缩小显示时，一个屏幕像素可能对应多个原图像素，精确选点请使用 100% 模式。
5. 点击“清除选区”或按 `Esc` 清除结果。

## 拟合数据表

- 在“图片分析”页选定像素或矩形后，点击“加入拟合”，自动跳转到“拟合数据”页并追加一行。没有选区时按钮不可用。
- 表格有 R、G、B、厚度四列。单像素添加其 RGB 值；矩形添加各通道均值，保留计算精度，不使用结果面板中四舍五入后的数值。
- 新行厚度为空。双击该行，或选中后点击“填写 / 修改选中行”，可以手动输入厚度及修改 RGB。厚度应统一单位，输入非负数；RGB 接受 0–255 内的小数。
- 第一次填写空白厚度可直接保存。覆盖已有数值或清空已有厚度时，会先列出旧值与新值并弹出警告，默认选择“否”；取消后所有原值保持不变。
- 可用 Ctrl / Shift 选择多行，点击“删除选中行”或按 Delete。删除前会提示删除行数并要求确认，默认选择“否”。
- 表格左侧“参与拟合”列可点击勾选/取消，也可对焦点行按空格。新增、导入行默认勾选，支持“全部勾选”和“全部取消”。蓝色行选中状态用于编辑/删除，与参与拟合的勾选状态相互独立。
- 打开另一张图片或清除图片选区不会清空表格。请用“导出 TXT”保存；表格有未导出的修改时会弹出退出确认，导出后未再修改则可直接退出。

## HSV 线性拟合

1. 在“拟合数据”页填写厚度并勾选要使用的行。
2. 切换到“拟合”页，选择 H、S 或 V（默认 H），点击“开始 / 更新拟合”。
3. RGB 转换为 HSV 后，以所选分量为 x、厚度为 y 做包含截距的普通最小二乘拟合。模型为 `厚度 = 斜率 × 所选分量 + 截距`，所有勾选行等权。这是分别针对单个 HSV 分量的拟合，不是 H/S/V 三变量联合回归。
4. 图中显示蓝色数据点与红色拟合直线；上方显示斜率、截距、R² 和数据点数量。纵轴厚度单位与输入一致。

H 是色相，范围 `[0°,360°)`；S 是饱和度，V 是 HSV 明度，均用百分比 `[0%,100%]`。因此 H 拟合斜率的单位是“厚度单位/度”，S/V 拟合斜率是“厚度单位/百分点”。转换使用图片中已有的 RGB 编码值，不进行线性光转换；V 不代表物理亮度。

H 是环形角度，359° 和 1° 相邻。对于跨越 0° 的数据，可勾选“H 跨 0° 展开”，将 H≥180° 的值减去 360°，改用 `[-180°,180°)`。例如 359° 转为 −1°；展开会将断点移到 180°，并非适合所有数据范围，不是自动展开多圈色相。S/V 不使用该设置。

至少需要两行有效数据，并且所选 HSV 分量不能全部相同。勾选行缺少厚度时会指出所在行；灰色、白色和黑色（R=G=B）没有定义色相，H 模式会提示取消勾选或改用 S/V。近灰色的低饱和度数据可能导致 H 不稳定，请结合样品情况选择分量。G=0 本身不再阻止拟合。R² 按 `1 - Σ(y - ŷ)² / Σ(y - y均值)²` 计算；厚度全部相同时 R² 未定义，界面会明确显示。

修改、增删数据、改变勾选状态或切换分量/展开设置后，旧参数与图表会清除，需要重新点击拟合。矩形数据先取各通道 RGB 均值，再转换为 HSV；这不是逐像素 HSV 的平均。原始四列表格和 TXT 文件保持兼容。

## TXT 导入与导出

- 顶部“图片分析”“拟合数据”和“拟合”页签采用大号粗体、加大点击区域，当前页签以蓝底白字突出显示。
- 在“拟合数据”页点击“导出 TXT…”，选择位置即可保存全部行，包含表头及空白厚度。覆盖已有文件时系统会要求确认。导出保留表格中的数值精度。
- TXT 仍为 R、G、B、厚度四列，保存所有行（包括未勾选行），不保存勾选状态或拟合结果。重新导入后所有行默认勾选，拟合前请检查需要参与的行。
- 点击“导入 TXT…”，选择文件后将数据追加到现有表格末尾，不覆盖原行。整份文件校验通过后才追加；格式错误会报告行号，不会导入部分数据。重复导入会追加重复行。
- 文件使用 UTF-8 编码（支持 BOM），列顺序固定为 R、G、B、厚度。导出以 Tab 分隔；导入也接受英文逗号或空格分隔。首行表头可省略，厚度表头也可写为 `thickness`。
- 厚度为空时，使用 Tab 或逗号分隔，并保留第四个空字段，例如 `10,20,30,`。每行必须有四列，空白行会忽略。RGB 须为 0–255 的有限数值，厚度须为非负有限数值或空白。
- 文件不记录厚度单位，合并不同来源的数据前请确保单位一致。

示例 TXT（此处用空格分隔，数值为示例）：

```text
R G B 厚度
120.5 80.25 62 15.0
98 75 43 20.0
```

## 统计约定

- 坐标以应用 EXIF 方向信息后的图像左上角为 `(0, 0)`，x 向右、y 向下。
- 选区包含起点与终点像素。统计始终基于原始分辨率图像，不使用缩放后的显示图像。
- 通道顺序为 RGB，数值范围为 0–255；均值与标准差显示 4 位小数。
- 每通道独立计算均值 `μ = Σv / N` 和总体标准差 `σ = sqrt(Σ(v - μ)² / N)`，其中 N 为选区像素总数，不使用样本标准差的 N−1。
- Pillow 解码后统一转换为 8 位 RGB。灰度图会复制到三个通道，调色板图会展开，RGBA 图片会忽略透明度并显示和统计其 RGB 值（包括完全透明像素）；不进行背景合成、ICC 色彩管理或线性光转换。
- 多帧或多页文件仅读取第一帧/页。高位深及浮点灰度图会提示先转换，避免隐式裁剪数值。此工具用于 RGB 数值分析，不作厚度反演或物理标定。

## 验证

```powershell
python -m unittest discover -s tests -v
```

算法测试覆盖已知像素的统计量、边界、反向选区、缩放坐标和文件读取。另可运行 `python tests/gui_smoke.py` 验证真实 Tk 窗口中的鼠标交互（会短暂创建窗口）。

运行 `python tests/gui_fitting.py` 可验证拟合表格的追加、编辑、输入校验和修改/删除/退出的取消确认分支（会短暂创建窗口）。

运行 `python tests/gui_txt.py` 可验证 TXT 导入导出、取消操作、错误处理、导出状态记录及最小窗口下按钮布局。TXT 解析和文件往返测试包含在上面的单元测试命令中。

运行 `python tests/gui_regression.py` 可验证行勾选、HSV 拟合、H/S/V 切换、跨零色相展开、图表重绘、无效数据提示及数据变化后结果清除。颜色转换、已知直线、含噪声数据和 R² 边界情形包含在单元测试中。
