# hBN 光学对比度标定

用于尝试 hBN / 约 285 nm SiO₂ / Si 的反射图像、约 0–30 nm 厚度范围的经验标定。本目录是项目唯一保留的程序版本，可独立运行。

双击本目录的 `start.bat` 启动。

## 采样和拟合

1. 打开图片，点击 **background**，在邻近的裸衬底上按住左键拖出矩形区域。
2. 点击 **signal**，在 hBN 内部厚度均匀的位置拖出矩形。避开边缘、褶皱、污染和过曝位置。
3. 松开鼠标后，显示两个矩形的坐标、像素数及三个通道的对比度。支持反向拖拽、拖出边界时裁剪，也支持单击取单像素。
4. 点击“加入拟合”，把三个完整精度的对比度加入表格，双击行手动填写 AFM 测得的厚度，单位为 **nm**。
5. 在“拟合数据”页勾选参与标定的行。在“拟合”页默认使用 **C_G**，点击“开始 / 更新拟合”。可切换 **C_B** 或 **C_R** 再拟合，对照同批样品的表现。
6. 查看数据点、直线、斜率、截距、R²、训练 RMSE；勾选“查看厚度残差”可检查残差是否随对比度出现弯曲趋势。

“适应窗口”看全图，“100% 显示”恢复原始像素比例。光标放在图片上时，滚轮向上放大、向下缩小，尽量保持光标下的位置不变（图片边缘或整图居中时受边界限制）。图片超出显示区域后，按住鼠标右键拖动画面，或使用滚动条浏览。左键仍用于 background / signal 的单点或矩形采样；左键选区过程中暂停缩放和右键移动，避免选区偏移。

滚轮通常支持 5%–3200% 缩放；特大图片允许缩小到适应窗口所需比例。放大仅渲染当前可见区域，不创建整幅超大放大图。缩放和右键移动不会改变已有选区、拟合数据或厚度计算结果；统计始终使用原始分辨率的像素。矩形包含鼠标起点和终点像素。background 可复用于当前图片中的不同 signal 区域；打开新图片会恢复适应窗口并清除两个区域，已添加的表格行不受影响。

## 厚度计算

先在“拟合”页完成线性拟合，再返回“图片分析”页，选取待测样品的 **background** 和 **signal**，点击 **厚度计算**。结果显示厚度（nm）、实际使用的通道（C_R / C_G / C_B）和该通道的当前对比度。使用已拟合直线的完整精度参数计算 `厚度 = 斜率 × 当前对比度 + 截距`，无需将待测区域加入拟合表。

- 更换图片时保留已有拟合，可用于同一成像条件下的新样品；需要重新选择两个区域。
- 更改选区会清除旧厚度结果。更改拟合通道、表格数据或勾选状态会同时使旧拟合和厚度结果失效，需要重新拟合。
- 没有有效拟合、两个选区不完整、正在拖拽或拟合通道的背景均值为 0 时，按钮不可用，并显示原因。
- 当前对比度超出拟合数据范围时标注“外推”；预测为负值时如实显示并提示检查，不自动截断为 0。厚度结果仅在界面显示，不写入拟合表或 TXT。

## 计算约定

各通道先分别取区域内像素的算术平均，再计算：

`C_X = (mean(background_X) - mean(signal_X)) / mean(background_X)`，其中 X 为 R、G、B。

- 对比度无量纲，保留正负号。例如 `C_G=-0.2` 表示信号区 G 均值比背景高 20%；表格保存 `-0.2`，不是 `-20`。不取绝对值。
- 本版本采用 **图片中已有的 0–255 通道编码值**，不进行 gamma 线性化、ICC 色彩管理或暗电流校正。因此属于在固定成像条件下的经验标定，不等同于严格的光谱反射率测量。所有标定和待测图片必须使用同一套处理流程。
- 背景某通道均值为 0 时，该通道记为空白（未定义），其他有效通道仍可加入表格和拟合。三个通道均未定义时不能添加。
- 图像按 EXIF 方向读取，多帧/多页仅使用第一帧/页；透明图片忽略 Alpha，高位深或浮点灰度图需先转换为 8 位。
- 约 285 nm SiO₂ 和 0–30 nm hBN 是本项目的实验背景，并非程序内置的物理反演参数。程序不包含固定的文献标定系数。

默认模型：`厚度(nm) = a × C_G + b`。对三个通道均采用包含截距的等权普通最小二乘拟合。至少需要两行有效数据，所选通道不能全部相同；未填写厚度或所选对比度为空时，会提示行号。

R² 为 `1 - Σ(d - d预测)² / Σ(d - d均值)²`；厚度全部相同时显示未定义。RMSE 为 `sqrt(Σ(d - d预测)² / N)`，单位 nm，**是在参与拟合的样品上计算的训练误差，不是独立验证误差**。残差定义为“实测厚度 − 拟合厚度”。改变数据、勾选状态或通道后会清除旧拟合结果。

这是先尝试单通道线性标定的版本，未加入二次或三通道联合回归。若残差呈明显曲线趋势，应进一步验证分段或二次模型，不能仅凭较高 R² 认定整个 0–30 nm 范围均为线性。建议按不同薄片划分独立验证数据，并固定光源、曝光、白平衡和物镜。

## 数据管理

- 表格包含 **C_R、C_G、C_B、厚度(nm)** 四列及拟合勾选开关。新增、导入行默认勾选。
- 修改已有值和删除行前会警告确认；首次填写空白值可直接保存。未导出修改在退出前会提示。
- TXT 导出全部行（含未勾选行），保留空白字段和数值精度，不保存选区、图片、勾选状态或拟合结果。
- UTF-8 TXT 使用 Tab 分隔，必须包含对比度专用表头，避免混用旧版 RGB 四列表格。导入也支持英文逗号或空格；有空白字段时应使用 Tab/逗号。导入在完整校验后追加，错误会显示行号。
- 原始 RGB 表和色差表不能直接导入本版本，因为缺少配对背景信息，不能由这些表唯一恢复对比度。

示例格式（数值为示例，不是真实标定数据）：

```text
C_R,C_G,C_B,厚度(nm)
-0.05,-0.10,0.03,5
-0.10,-0.20,0.06,10
,-0.30,0.09,
```

## 运行和测试

需要 Python 3.10+、Tkinter、Pillow。在本目录运行：

```powershell
python -m pip install -r requirements.txt
python optical_contrast_inspector.py
python -m unittest discover -s tests -v
python tests/gui_workflow.py
python tests/gui_thickness.py
python tests/gui_navigation.py
```

测试使用合成数据验证正负对比度、区域均值、零背景、各通道线性拟合、TXT 及真实窗口中的拖拽、勾选、残差图和防误操作流程。
